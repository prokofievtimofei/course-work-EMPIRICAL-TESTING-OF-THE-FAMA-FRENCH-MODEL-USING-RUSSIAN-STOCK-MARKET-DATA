# Empirical Testing of the Fama-French Five-Factor Model on Russian Stock Market Data

---

## 📌 О проекте

Эмпирическая проверка применимости пятифакторной модели Fama–French (FF5) на данных российского фондового рынка за период **июль 2016 — февраль 2026** (116 месяцев, 137 акций MOEX).

Дополнительно — субпериодный анализ вокруг **санкционного шока февраля 2022** как естественного эксперимента по трансформации факторной структуры изолированного рынка.

---

## 📊 Данные

| Источник | Описание |
|----------|----------|
| MOEX ISS API | Котировки 137 акций TQBR, индекс IMOEX |
| difan.xyz | Фундаментальные данные: баланс, P&L, рыночная капитализация |
| ЦБ РФ | Ключевая ставка как прокси безрисковой ставки |

**Выборка:** 260 → 137 акций после 6 этапов фильтрации (активный статус, история с 2017, доля пропусков < 30%, наличие фундаментальных данных).

---

## ⚙️ Методология

- Факторы построены по стандартной методологии Fama & French (2015): независимые сортировки 2×3, ежегодная ребалансировка в июне, взвешивание по капитализации
- Тестовые активы: 22 портфеля (5×5 по квинтилям Size × B/M, 3 исключены – компромисс для увеличения степеней свободы)
- Основной критерий качества: **GRS-тест** (Gibbons, Ross & Shanken, 1989)
- Робастность: equally weighted спецификация
- Субпериодный анализ: до февраля 2022 (67 мес.) и после (49 мес.)

## 📈 Результаты

### GRS-тест

| Показатель | Значение |
|------------|----------|
| GRS F-статистика | **0.719** |
| p-value | **0.809** |
| Mean \|α\| | 0.372% в месяц |
| Число портфелей | 22 |

**FF5 не отвергается на российских данных** — ни один из 22 портфелей не показывает значимых аномальных доходностей на уровне 5%.

### Факторные премии (% в месяц)

| Фактор | Среднее | t-stat |
|--------|---------|--------|
| MKT | −0.29 | −0.52 |
| SMB | **0.72** | 1.47 |
| HML | −0.22 | −0.61 |
| RMW | 0.01 | 0.03 |
| CMA | **0.76** | 1.91 |

### Субпериодный анализ: влияние санкций

| Фактор | До фев. 2022 | После фев. 2022 |
|--------|-------------|-----------------|
| MKT | +0.45% | **−1.30%** |
| SMB | −0.10% | **+1.85%** (t=1.79) |
| CMA | +0.73% | +0.81% |

Санкционный шок резко усилил SMB: крупные экспортёры и госструктуры пострадали несимметрично по сравнению с малыми компаниями внутренней ориентации. GRS не отвергает модель ни в одном субпериоде (p=0.562 и p=0.530).
